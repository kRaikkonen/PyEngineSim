# EngineSim v2 core

One compiled core, written once (Rust), used by the phone, the desktop studio and the tests alike.
The design is `docs/REDESIGN_V2.md`; here so far are stage **S1** (the single firing event) and
stage **S2** (the exhaust it discharges into).

| | |
|---|---|
| `sound/` | the real-time sound model: the cylinders (each one's gas solved live), the exhaust as a network of pipes, the loudness curve |
| `capi/` | the C ABI (`include/enginesim_core.h`), built as a DLL / dylib and a static library |
| `../engine_sim/corelib.py` | Python's door into it (ctypes) |
| `../engine_sim/core_spec.py` | the bake side: an engine preset → the core's spec |
| `../engine_sim/core_exhaust.py` | the exhaust topologies: the A3's by hand, any other car's guessed from its preset |
| `../engine_sim/core_voice.py` | the studio's v2 voice: simulator → operating point → core → sound card (key **N** in the app) |
| `../tools/v2_render.py` | a drive rendered to WAV through the core, and through the old chain beside it |

No external crates: the build needs only the Rust toolchain.

## Build and test

```bash
cargo test --release
```

```bash
cargo build --release
```

```bash
python ../tools/core_check.py
```

- `cargo test` — the model against closed forms (adiabat, choked blowdown), its own conservation of mass
  and energy, a racing head's overlap, block-length independence, and "the render path never allocates".
- `tools/core_check.py` — the core against the same equations integrated independently in Python
  (it must converge on them, first order in the time step), and against `gas_truth.py`.

```bash
cargo run --release --example event
```

```bash
cargo run --release --example bench
```

`event` prints what one exhaust event looks like across speed and load; `bench` what the cylinders cost.

## What is in `sound` so far

- `gas.rs` — the gas (γ falls with temperature) and the compressible orifice, choked below the critical
  pressure ratio. The flow function is a polynomial fit of the isentropic law (`nozzle_fit.rs`, generated by
  `tools/gen_nozzle_fit.py`, accurate to 3e-9), so the innermost function has no powers in it.
- `cylinder.rs` — one cylinder: piston work, a Wiebe burn, Hohenberg wall heat, and both valves, with the
  valve step solved implicitly so a small volume between two open valves cannot ring. No two cycles burn
  alike (`Control::ccv`): the start, the speed and the completeness of each burn vary.
- `network.rs` — the pipes. Travelling pressure waves in delay lines; four kinds of node (junction, valve,
  orifice, open end). A muffler is fat pipes, a catalyst a lossy pipe behind a resistance, a turbine an
  orifice whose resistance the operating point sets. Mass is conserved exactly. Flow noise is made where the
  flow loses pressure, scaled by the local speed. The open end reflects as an unflanged pipe does and
  radiates as a monopole.
- `engine.rs` — the crank, the cylinders, the network, and the output stage: the loudness curve
  (`Control::dynamics`: how much of the real dynamic range is played) and a limiter that only protects.
  The operating point is read every 32 samples and ramped.
- `control.rs` — the operating point, and the lock-free mailbox it crosses threads in.
- `math.rs` — `exp`, `ln`, `sin`/`cos` written here as plain arithmetic: the same bits on every platform.

## Not here yet

Only the exhaust speaks, and the listener stands 1 m from the tailpipe. Still to come (stage S3): the
steepening of large waves in the pipes, the intake side, the engine block and its mechanical noise, the turbo
machine's own sound, the cabin. And the numbers that only recordings can set: the A3's pipe dimensions are
typical of the layout, not measured, and the flow-noise amounts are starting values.
